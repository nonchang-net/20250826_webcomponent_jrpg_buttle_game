# バトルルール定義1

このwebアプリは、RPGのバトル進行ルール複数定義し差し替えられるように実装しています。

この文章では、「ターン型バトル」の進行ルールを定義します。

## 進行フロー

1. ゲーム開始時
    - ランタイムパラメータを初期化します。actorマスターのhpとmpはヒットポイントとマジックポイントを示します。この値を元に、最大HP・現在HP、最大MP・現在MPの変数に展開してください。回復コマンドの実行時に、最大HPを超えて回復することはありません。
    - 続いて、ランダムで以下「1a」「1b」のどちらかを実行します。

    - 1a: メッセージ「魔物の群れが現れた！ 魔物の群れは、こちらが身構える前に襲いかかってきた！」
        - 敵(is_enemy=true)が先攻で開始します。それぞれ手持ちのインベントリから可能な行動を選択し、行動します。
        - 行動順番は、actorマスターの「agility」に乱数0〜9を加えたものの数字の多い順から行動します。
        - 全ての敵の行動完了後は、「4. 全滅評価・討伐評価」の上で、継続時は「2. ユーザ行動選択」に進みます。
    - 1b: メッセージ「魔物の群れが現れた！ コマンド？」と表示し、「2. ユーザ行動選択」に進みます。

2. ユーザ行動選択
    - 味方キャラクターの行動を順次選んでいきます。
        - 今行動を決めようとしているキャラ名をメッセージ枠に表示します。「勇者の行動を選択してください」と表示してください。
        - escキーで、決定内容をキャンセルして戻れるように実装してください。
        - 先頭キャラクターのコマンド選択はキャンセルできません。
    - 全てのキャラクターの行動を決定したら、「3. ターン実行ループ」に進みます。

3. ターン実行ループ
    - 行動順番は、actorマスターの「agility」に乱数0〜9を加えたものの数字の多い順から行動します。
    - ダメージを与える行動が実行された際は、「4. 全滅評価・討伐評価」を行います。勝利・敗北が決まっていない場合は、次の行動actorが行動します。
    - 全てのactorの行動が完了したら、「2. ユーザ行動選択」に進みます。

4. 全滅評価・討伐評価
    - 敵味方問わず、HPが0になると行動不能になります。敵は表示一覧から消滅し、味方は行動不能と表示します。
    - 誰かが行動不能になったタイミングで、全滅評価・討伐評価を行います。
    - 敵がいなくなった場合は勝利です。「勝利しました！」と表示し、コマンドは「再プレイ」を表示します。再プレイ実行時は、ランタイムパラメータをマスターデータの内容で復旧して、「1. ゲーム開始時」に戻ります。
