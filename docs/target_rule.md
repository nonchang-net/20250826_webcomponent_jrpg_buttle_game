# ターゲット選択に関するルール

道具・魔法・敵のアクションに関するinventoryのマクロコマンドは、「自陣を対象とするものか否か」を示すコマンドが含まれている必要がある。
マクロコマンド中に、以下のどちらも含まれていない場合はエラーとする。

- 00d103f0-f9e1-4b61-a5c4-bf211a205412	味方を対象とする    SetTargetFriends
- a2540dff-b99d-4409-9f92-e113bf66c837	相手を対象とする    SetTargetOtherSides

## プレイヤーサイド

- マクロコマンド中、SetWholeTarget(23ca1336-358d-461b-8e74-20beebe59f98)がついている場合は、対象となる相手を選択するUIは表示しない。味方を対照するコマンドは味方全体に、相手を対象とするコマンドは敵全体に効果を及ぼす。
- SetWholeTargetがついていないマクロコマンドでは、味方一覧か相手一覧を選択するUIを挿入し、選んだ対象に効果を及ぼす。

## enemyサイド

- enemyの行動にはプレイヤーのUI操作は介在しないため、マクロコマンドの内容評価で効果対象を決定する。
- 効果対象を決定できなかった場合はエラーとする。

## 武器を道具として利用したときのルール

今回は実装しない。ターン評価中に「勇者はxxxを掲げた。しかし何も起こらなかった！」と表示する。
（将来的に、別マスターで「道具として武器を利用したときの効果定義マスター」を検討する可能性はある）
