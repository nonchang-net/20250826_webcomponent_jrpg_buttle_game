# 道具選択時の戻るボタンをカーソル選択可能に修正

## 変更した内容の概要

CommandMenuコンポーネントの道具選択メニューで、「戻る」ボタンを独立したボタンからアイテム一覧の末尾に統合し、カーソルキーで選択可能にした。currentItemsに戻るボタンを仮想アイテムとして追加し、executeSelectedItem()でisBackButtonフラグによる分岐処理を実装。戻るボタンには視覚的に区別するためのback-styleクラスを適用し、灰色系のスタイルで他のアイテムボタンと差別化した。

## なぜそのように変更しようと考えたか

従来の設計では「戻る」ボタンが一覧の外に分離されており、カーソルキーで選択できないため操作性に一貫性がなかった。Escapeキーでの戻る操作を知らないユーザーにとって、戻るボタンがカーソル選択できないのは不自然で使いにくい。RPGの伝統的なメニュー操作では、全ての選択肢がカーソルで選べることが一般的であり、この原則に従って統一的な操作感を提供するべきだった。

## 実装詳細

- currentItemsに戻るボタンを仮想アイテム({ id: '__back__', name: '戻る', isBackButton: true })として追加
- executeSelectedItem()にisBackButtonフラグによる条件分岐を追加
- showItemMenu()で戻るボタンをitemListContainer内に配置し、item-buttonクラスを適用
- .item-button.back-styleスタイルを追加して戻るボタンを視覚的に区別（グレー系色調）
- 戻るボタンも他のアイテムと同様にカーソルキーでの選択・決定操作が可能
