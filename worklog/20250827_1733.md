# 作業レポート - 20250827_1733

## 変更した内容の概要
- CommandEvaluatorの「攻撃点ルール適用」コマンドで攻撃者の基本攻撃力を考慮するよう修正しました（`baseDamage = actor.attack + this.register`）
- ActionResolverのダメージ計算に防御力を考慮する処理を追加しました（`finalDamage = baseDamage - targetDefence`、最低1ダメージ保証）
- これにより敵の攻撃が攻撃力50から防御力10を差し引いた40ダメージ（最低1）を与えるようになりました

## なぜそのように変更しようと考えたか
- 「攻撃点ルール適用」がレジスタ値（0）のみを使っていたため、敵の攻撃力が全く反映されていませんでした
- RPGの基本的なダメージ計算として「攻撃力 - 防御力」の仕組みが必要でした  
- マスターデータの「ランダム単純攻撃マクロ」でarg1=0が設定されているのは「武器補正なし」の意味であり、基本攻撃力は別途計算に含めるべきでした

- `/components/battle/command-evaluator.js` - executeApplyAttack()で攻撃者の基本攻撃力を加算するよう修正
- `/components/battle/action-resolver.js` - resolveEnemyAction()でのダメージ計算に防御力を考慮する処理を追加
