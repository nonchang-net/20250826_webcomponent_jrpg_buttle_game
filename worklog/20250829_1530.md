# バトルシステム - 回復薬(小)使用時のターゲット選択機能実装

## 変更した内容の概要
- ターゲット選択UIコンポーネント(`target-selector.js`)を新規作成し、味方・敵の選択画面を提供
- アクタークラスにアイテム所持・消費チェック機能(`hasItem`, `consumeItem`, `getItemQuantity`)を追加
- バトルシーンでアイテム選択後のマクロコマンド解析によるターゲット選択フローを実装
- アクションリゾルバーのアイテム使用処理をマクロベースシステムに更新し、アイテム消費機能を組み込み

## なぜそのように変更しようと考えたか
- 回復薬(小)の薬効回復マクロに「味方を対象とする」コマンドが含まれており、使用時に味方選択が必要
- 「消費型アイテム評価」コマンドによりアイテムを1個消費する仕様のため、所持数チェックと消費処理が必要
- ターゲット選択ルールに基づき、マクロコマンドを動的に解析してUI表示を制御する汎用的な仕組みを構築
